# 예배계획 (시각적 입력 상태 구분 및 텔레그램 번호 매김 업데이트)

예배 일정 작성 중 빈칸을 놓치지 않도록 미입력 필수 칸을 분홍색으로 강조하고, 선택 항목인 특이사항 칸은 연한 노란색으로 구분하며, 텔레그램 복사 시 상단 `✅예배 일정` 제목과 `1. 2. 3.` 순번이 자동으로 포함되도록 개선합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> 요청하신 3가지 변경 사항을 모두 반영한 계획입니다. 아래 내용을 확인하신 후 **Proceed**를 눌러주시면 즉시 코드에 적용합니다.

- **확정 사항 1 (`특이사항` 입력칸 연한 노란색 적용)**: `5. 특이사항` 입력칸은 선택 입력 항목임을 한눈에 알 수 있도록 전체적으로 연한 노란색(`bg-amber-50 border-amber-200`) 배경을 상시 적용합니다.
- **확정 사항 2 (미입력 일반 칸 분홍색 강조 표시)**:
  - `2. 설교주제`, `4. 묵도성구`, 그리고 설교장소/설교자에서 `기타`를 선택했을 때 나타나는 직접 입력칸이 비어 있을 경우 **연한 분홍색(`bg-rose-50 border-rose-300`)**으로 칠해 작성 누락을 방지합니다.
  - 텍스트를 한 글자 이상 입력하면 즉시 기본 흰색(`bg-white border-slate-200`)으로 바뀌어 작성이 완료되었음을 직관적으로 보여줍니다.
- **확정 사항 3 (텔레그램 복사 양식에 `✅예배 일정` 헤더 및 `1. 2. 3.` 순번 적용)**:
  - 텔레그램 추출 텍스트 최상단에 항상 `✅예배 일정` 문구가 먼저 표시됩니다.
  - 추출되는 첫 번째 예배 행부터 순서대로 `1. `, `2. `, `3. ` 번호가 자동으로 붙어 복사됩니다.

## 1. Overview & Core Concept

- **What It Does**: 주일·삼일예배 기록 중 아직 작성하지 않은 필수 입력란(설교주제, 묵도성구 등)을 시각적인 색상(분홍색)으로 즉시 식별하게 해 주고, 텔레그램 공유 시 제목(`✅예배 일정`)과 일련번호(`1.`, `2.`, `3.`)가 완비된 보고 양식을 원클릭으로 생성합니다.
- **Target Audience / Persona**: 매월·매주 예배 계획을 빠짐없이 작성하고 텔레그램으로 깔끔하게 공유해야 하는 담당자.
- **Key Value**: 빈칸 누락 실수를 원천 방지하고, 텔레그램에서 별도로 번호나 제목을 타이핑할 필요 없이 붙여넣기만 하면 보고가 끝납니다.

---

## 2. User Experience & Visual Design

- **Visual Input State Coloring**:
  - **일반 입력칸 (미입력 상태)**: `bg-rose-50/90 border-rose-300 placeholder:text-rose-400`를 적용하여 비어 있는 칸이 눈에 잘 띄도록 구성합니다.
  - **일반 입력칸 (입력 완료 상태)**: 내용이 채워지면 즉시 `bg-white border-slate-200`로 전환됩니다.
  - **특이사항 입력칸**: `bg-amber-50/90 border-amber-200 placeholder:text-amber-600/60`을 적용하여 전체적으로 부드러운 연한 노란색 톤을 유지합니다.

- **Telegram Output Format**:
```text
✅예배 일정

1. [키토본부]11월01일(주일) {김요안}/묵도:

2. [키토본부]11월04일(삼일) {김요안}/묵도:

3. [키토본부]11월08일(주일) {김요안}/묵도:
```

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 기간 필터링 시 순번(`1. 2. 3.`) 자동 재정렬**
  - *Chosen Approach*: 시작날짜와 끝날짜로 특정 기간만 추출하더라도 추출된 목록의 첫 번째 항목부터 항상 `1.`, `2.`, `3.` 순서로 번호가 매겨지도록 처리합니다.
  - *Why*: 텔레그램에 부분 기간만 복사해 붙여넣을 때도 번호가 중간 숫자(예: `5.`)부터 시작하지 않고 자연스럽게 `1.`부터 시작해야 깔끔한 보고 메시지가 됩니다.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:
```
┌──────────────────────────────────────────────────────────────────────────┐
│                         Worship Entry Row (입력 행)                      │
│  ├─ 날짜/예배구분 : 달력 팝오버 + (주일: 검정 / 삼일: 회색)              │
│  ├─ 1. 설교장소   : 드롭다운 + [기타 선택 시 미입력=분홍색 / 입력=흰색]  │
│  ├─ 2. 설교주제   : 텍스트 입력 [미입력=분홍색 / 입력=흰색]              │
│  ├─ 3. 설교자     : 드롭다운 + {기타 선택 시 미입력=분홍색 / 입력=흰색}  │
│  ├─ 4. 묵도성구   : 텍스트 입력 [미입력=분홍색 / 입력=흰색]              │
│  └─ 5. 특이사항   : 텍스트 입력 [상시 연한 노란색 배경]                  │
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                     Telegram Formatter Engine (추출부)                   │
│  Header : "✅예배 일정"                                                  │
│  Lines  : "{index + 1}. [{장소}]{MM}월{DD}일({구분}) {주제}{{설교자}}/묵도:{성구}" │
└──────────────────────────────────────────────────────────────────────────┘
```

- **Interactive Component & State Mapping**:
  - **동적 배경색 헬퍼**: 입력값의 `trim().length === 0` 여부를 실시간 검사하여 일반 필수 입력칸에는 분홍색 스타일 클래스를, 입력된 칸에는 흰색 스타일 클래스를 부여합니다.
  - **텔레그램 문자열 조합**: 추출 대상 배열(`extractedEntries`)을 순회하며 각 줄 앞에 `${idx + 1}. `을 붙이고, 최상단에 `✅예배 일정`을 결합하여 미리보기 및 클립보드 복사에 동일하게 반영합니다.
