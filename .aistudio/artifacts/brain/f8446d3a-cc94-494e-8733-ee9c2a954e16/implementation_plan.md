# 예배 기록 및 텔레그램 양식 추출기 (Worship Log & Telegram Formatter)

삼일예배와 주일예배의 설교주제, 설교자, 묵도성구, 설교장소를 날짜순으로 편리하게 기록하고, 지정된 텔레그램 보고 양식(`[장소]MM월DD일(삼일/주일) 설교주제{설교자}/묵도:성경구절`)으로 즉시 변환하여 복사할 수 있는 전용 워크스페이스입니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> 질문 응답을 통해 확정된 핵심 사양입니다. 아래 내용을 확인하신 후 **Proceed**를 눌러주시면 바로 구현을 시작합니다.

- **확정 사항 1 (일정 생성 및 다중 장소 기록)**: 11월 1일(일요일/주일예배), 11월 4일(수요일/삼일예배), 11월 8일(일요일/주일예배) 순으로 월별 주일·삼일 예배 일정이 자동 생성되며, 동일한 날짜에 여러 설교장소 행을 추가할 수 있습니다.
- **확정 사항 2 (텔레그램 텍스트 추출 방식)**: 기록된 데이터를 입력한 순서(날짜순)대로 정렬하여 한 번에 복사할 수 있는 단일 텔레그램 텍스트 블록으로 실시간 추출합니다.
- **확정 사항 3 (설교장소 및 설교자 드롭다운 구성)**:
  - **설교장소**: `키토본부`, `빌록시`, `푸힐리`, `오따발로`, `기타` 5가지 옵션으로 구성하며, `기타` 선택 시 직접 타이핑한 장소명이 `[직접입력장소]` 형태로 반영됩니다.
  - **설교자**: `김요안`, `지파장님영상`, `총회장님영상`, `특별영상`, `기타` 5가지 옵션으로 구성하며, `기타` 선택 시 직접 타이핑한 설교자명이 `{직접입력설교자}` 형태로 반영됩니다.
  - **예배 구분**: 각 행마다 드롭다운으로 `주일` 또는 `삼일`을 선택 및 변경할 수 있습니다.
  - **묵도성구 및 설교주제**: 사용자가 자유롭게 타이핑한 그대로 양식에 반영됩니다.

## 1. Overview & Core Concept

- **What It Does**: 매주 반복되는 주일예배와 삼일예배 기록을 표 형태의 편집기에서 빠르게 입력·수정하고, 텔레그램 공유용 표준 문자열로 자동 포맷팅하여 클립보드에 복사해 주는 도구입니다.
- **Target Audience / Persona**: 지교회 및 본부 예배 보고 담당자, 주간/월간 예배 현황을 취합하여 텔레그램으로 공유하는 관리자.
- **Key Value**: 수작업으로 괄호(`[]`, `{}`, `()`)와 날짜 양식을 일일이 맞출 필요 없이, 드롭다운 선택과 핵심 텍스트 입력만으로 오타 없는 정형화된 텔레그램 메시지를 즉시 생성합니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **초기 진입 및 월별 일정 표시**: 기본으로 11월 예배 일정(11월 01일 주일, 11월 04일 삼일, 11월 08일 주일, 11월 11일 삼일...)이 순서대로 나열되며, 상단에서 연도/월을 전환하거나 기본 예시 데이터를 불러올 수 있습니다.
  2. **항목별 빠른 입력**:
     - 각 날짜 행에서 **설교장소 드롭다운**(`키토본부`, `빌록시`, `푸힐리`, `오따발로`, `기타`)을 선택합니다 (`기타` 선택 시 우측/하단에 즉시 직접 입력창 활성화).
     - **예배 구분 드롭다운**(`주일`, `삼일`)을 확인하거나 변경합니다.
     - **설교주제** 텍스트 입력란에 주제를 기록합니다.
     - **설교자 드롭다운**(`김요안`, `지파장님영상`, `총회장님영상`, `특별영상`, `기타`)을 선택합니다 (`기타` 선택 시 직접 입력창 활성화).
     - **묵도성구** 텍스트 입력란에 성경구절(예: `마13:24-27`)을 기록합니다.
  3. **동일 날짜 장소 추가 및 행 관리**: 같은 날 여러 장소의 예배를 기록해야 할 때 행 우측의 `+ 같은 날 추가` 버튼으로 즉시 해당 날짜의 새 기록 칸을 복제·추가하거나 불필요한 행을 삭제할 수 있습니다.
  4. **실시간 텔레그램 양식 미리보기 및 복사**: 우측(데스크톱) 또는 하단(모바일)의 실시간 미리보기 패널에서 `[장소]11월01일(주일) 설교주제{설교자}/묵도:성경구절` 형식의 결과를 즉시 확인하고, `텔레그램 텍스트 전체 복사` 버튼을 눌러 클립보드에 복사합니다.

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 정돈된 엔터프라이즈 스프레드시트 및 에디토리얼 로그북 스타일 (높은 가독성, 명확한 입력 포커스, 불필요한 장식 배제).
  - *Color Palette & Mood*:
    - **60% Dominant Neutral Canvas**: 눈의 피로를 줄이는 깨끗한 오프화이트/슬레이트 캔버스 (`bg-slate-50`, 텍스트 `text-slate-900`).
    - **30% Structural Surfaces**: 선명한 1px 헤어라인 보더(`border-slate-200`)와 화이트 입력 서피스(`bg-white`).
    - **10% Accent Budget**: 주요 액션(복사 버튼, 행 추가, 활성 포커스 링)에 집중된 딥 인디고/블루 포인트(`bg-slate-900`, `focus:ring-blue-600`).
  - *Typography & Hierarchy*:
    - **Display / Header**: `Plus Jakarta Sans` 및 깔끔한 한글 산세리프 조화로 명확한 섹션 타이틀 구성.
    - **Body & Inputs**: `Public Sans` / 시스템 산세리프 기반의 14px~15px 고밀도 입력 폼.
    - **Tabular Numerals & Preview**: 날짜(`11월01일`) 및 텔레그램 추출 텍스트 미리보기 영역에 `tabular-nums` 및 고정폭 스타일(`JetBrains Mono`)을 적용하여 줄 맞춤과 괄호 구조를 선명하게 표현.
  - *Component Styling & Layout*: 1440px 데스크톱 기준 좌측 65% 영역에는 고밀도 예배 기록 테이블/리스트 에디터를 배치하고, 우측 35% 영역에는 스티키(Sticky) 형태의 실시간 텔레그램 텍스트 추출 프리뷰 및 원클릭 복사 패널을 배치합니다.

- **Interactive Feedback & Motion**:
  - `기타` 선택 시 자연스럽게 나타나는 커스텀 텍스트 입력 필드(자동 포커스 지원).
  - `전체 복사` 및 `개별 줄 복사` 클릭 시 150ms 이내의 즉각적인 체크 아이콘 전환 및 복사 완료 토스트 피드백 제공.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 11월 1일(일요일) 기준 주일·삼일 교차 일정 생성 로직**
  - *Chosen Approach*: 사용자가 요청한 대로 11월 1일(주일), 11월 4일(삼일), 11월 8일(주일), 11월 11일(삼일) 패턴이 정확히 시작되도록 기본 11월 달력 기준(11월 1일이 일요일인 기준 연도 또는 월별 일/수요일 자동 계산)으로 일정을 생성하며, 날짜 직접 수정 및 행 추가도 모두 허용합니다.
  - *Why*: 요청하신 날짜 흐름(`11월01일(주일)` → `11월04일(삼일)` → `11월08일(주일)` → `11월11일(삼일)`)을 즉시 빈칸으로 제공하여 별도 날짜 계산 없이 바로 내용을 채워 넣을 수 있게 합니다.

- **Decision 2: 브라우저 자동 저장 (LocalStorage Persistence) 및 샘플/초기화 지원**
  - *Chosen Approach*: 입력 중인 모든 예배 기록을 브라우저 `localStorage`에 실시간 자동 저장하고, 예시 양식 데이터로 미리 확인하거나 빈 양식으로 초기화하는 컨트롤을 함께 제공합니다.
  - *Why*: 여러 주차의 설교주제와 묵도성구를 작성하는 도중 실수로 새로고침하더라도 기록이 유실되지 않도록 보호합니다.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:
```
┌──────────────────────────────────────────────────────────────────────────┐
│                     Top Navigation Bar (3-Zone Contract)                 │
│  [예배 기록 매니저]        [월별 일정 · 작성 내역 · 양식 안내]   [전체 복사] │
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │
         ┌───────────────────────────┴───────────────────────────┐
         ▼                                                       ▼
┌─────────────────────────────────────────┐   ┌────────────────────────────┐
│      Worship Schedule Editor (65%)      │   │  Telegram Output Panel(35%)│
│ ┌─────────────────────────────────────┐ │   │ ┌────────────────────────┐ │
│ │ Toolbar: 월 선택 / 행 추가 / 초기화 │ │   │ │ 출력 옵션 (빈 행 제외 등)│ │
│ └─────────────────────────────────────┘ │   │ └────────────────────────┘ │
│ ┌─────────────────────────────────────┐ │   │ ┌────────────────────────┐ │
│ │ Date Row (e.g., 11월 01일 / 11월 04일)│ │   │ │ 실시간 텔레그램 텍스트 │ │
│ │  ├─ 예배구분 Select: (주일 | 삼일)  │ │   │ │ [장소]날짜(요일) 주제  │ │
│ │  ├─ 설교장소 Select + [기타 입력창] │ │   │ │ {설교자}/묵도:성구     │ │
│ │  ├─ 설교주제 Input                  │ │   │ └────────────────────────┘ │
│ │  ├─ 설교자 Select   + {기타 입력창} │ │   │ ┌────────────────────────┐ │
│ │  ├─ 묵도성구 Input                  │ │   │ │ 원클릭 클립보드 복사   │ │
│ │  └─ Actions: [+ 같은 날 추가] [삭제]│ │   │ └────────────────────────┘ │
│ └─────────────────────────────────────┘ │   └────────────────────────────┘
└─────────────────────────────────────────┘
```

- **Data Model & State**:
  - `WorshipEntry`:
    - `id`: 고유 식별자 (`string`)
    - `month`: 월 (`number`, 기본값 `11`)
    - `day`: 일 (`number`, 예: `1`, `4`, `8`, `11`...)
    - `worshipType`: `'주일' | '삼일'` (드롭다운 선택)
    - `locationPreset`: `'키토본부' | '빌록시' | '푸힐리' | '오따발로' | '기타'`
    - `locationCustom`: `string` (`locationPreset === '기타'`일 때 사용되는 사용자 입력값)
    - `topic`: `string` (설교주제)
    - `preacherPreset`: `'김요안' | '지파장님영상' | '총회장님영상' | '특별영상' | '기타'`
    - `preacherCustom`: `string` (`preacherPreset === '기타'`일 때 사용되는 사용자 입력값)
    - `scripture`: `string` (묵도성구)

- **Interactive Component & State Mapping**:
  - **일정 자동 생성기**: 11월 1일(주일)부터 시작해 +3일(삼일예배, 수요일), +4일(주일예배, 일요일) 간격으로 해당 월의 모든 주일·삼일 예배 행을 자동 구성합니다.
  - **드롭다운 + 기타 직접 입력 연동**:
    - 장소가 `기타`가 아니면 `[키토본부]`처럼 선택된 값을 사용하고, `기타`이면 옆에 나타나는 텍스트 입력창의 값을 `[입력값]`으로 즉시 포맷팅합니다.
    - 설교자가 `기타`가 아니면 `{김요안}`처럼 선택된 값을 사용하고, `기타`이면 옆에 나타나는 텍스트 입력창의 값을 `{입력값}`으로 즉시 포맷팅합니다.
  - **텔레그램 포맷터 엔진**:
    - 날짜는 두 자리 숫자(`11월01일`, `11월04일`, `11월08일`)로 자동 패딩(`padStart(2, '0')`)합니다.
    - 각 행을 `[{장소}]{MM}월{DD}일({주일|삼일}) {설교주제}{{설교자}}/묵도:{묵도성구}` 문자열로 변환하고 줄바꿈으로 연결하여 입력 순서(날짜순)대로 출력합니다.
    - 작성 완료된 행만 추출하거나 전체 행을 추출하는 필터 토글과 원클릭 클립보드 복사를 지원합니다.
